# Security Policy

## Supported versions

Only the latest release of each project receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, use the **"Report a vulnerability"** button in the **Security** tab of the affected repository. This sends a private report that only the maintainer can see.

Helpful details:
- Which version and platform are affected
- Steps to reproduce or a proof of concept
- The possible impact

## What happens next

- I will confirm receipt within 7 days.
- I will investigate, prepare a fix and publish a new release as soon as possible.
- You will be credited in the release notes unless you prefer to stay anonymous.

## Out of scope

- Vulnerabilities in third-party libraries – please report them to the respective project. I will update the dependency once a fix is available.
