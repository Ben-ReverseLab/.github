# Contributing

Thanks for taking the time to contribute!

This applies to all projects by Ben-ReverseLab unless a repository has its own guide.

## Ways to help

- Report a bug or suggest a feature by opening an issue (please use the templates)
- Improve the documentation
- Fix an open issue – look for the `good first issue` label

## Before you start

For anything larger than a small fix, please open an issue first so we can agree on the approach. That way nobody spends time on a change that does not fit the project.

## Development setup

See the **Installation** section of the project's README. Most projects can be started with a few commands after cloning:

    git clone https://github.com/Ben-ReverseLab/<repository>
    cd <repository>

## Pull requests

1. Create a branch from `main`.
2. Keep each pull request focused on one change.
3. Run the tests and the formatter before opening the PR.
4. Describe what you changed and why, and link the related issue.

## Commit messages

Use short, descriptive messages in the imperative mood, for example `Add CSV export` or `Fix crash on empty folder`.

## Response time

These are one-person projects. I usually reply within 7 days.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
