# Getting help

1. **Check the README** of the project – most questions about installation and usage are answered there.
2. **Ask a question** in the project's **Discussions** tab (or open an issue with the `question` label if a project has no Discussions).
3. **Found a bug?** Open an issue using the bug report template.
4. **Security problem?** Please follow the [security policy](SECURITY.md) instead of opening a public issue.

These are hobby projects maintained by one person, so help is given as time allows. Thanks for your patience!
